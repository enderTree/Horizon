## [月之暗面发布开源 2.8 万亿参数模型 Kimi K3](https://t.me/zaihuapd/42637) ⭐️ 9.0/10

月之暗面发布了 Kimi K3，全球首个开源的 2.8 万亿参数模型，在 Frontend Code Arena 评测中取得最高分，超越了之前的模型。该模型引入了新颖的 Kimi Delta Attention 和 Attention Residuals 架构。 此次发布代表了开源 AI 的重大飞跃，表明一个 2.8 万亿参数的模型可以公开获得，并在专业编程任务上超越竞争对手，有望加速 AI 辅助的前端开发。 Kimi K3 具有 100 万 token 的上下文窗口和原生视觉能力，基于 Kimi Delta Attention (KDA)和 Attention Residuals (AttnRes)架构构建。在 Frontend Code Arena 中，它获得了 1679 分，从之前 Kimi k2.6 的第 18 名跃升至第一。

telegram · zaihuapd · 7月18日 02:29

**背景**: Kimi Delta Attention 是一种高效的线性注意力机制，基于 Gated DeltaNet 构建，可减少长上下文的内存使用。Attention Residuals 是标准残差连接的即插即用替代方案，允许每一层选择性聚合之前的层。Frontend Code Arena 评测模型在代理式前端编程任务（如 HTML 和 React 应用开发）上的表现。

## [首次在地球类似行星的宜居带发现大气层](https://www.bbc.com/news/articles/cy4kdd1e0ejo) ⭐️ 8.0/10

天文学家在距离地球 48 光年的红矮星宜居带内，探测到了岩石系外行星 LHS 1140b 的大气层。这是首次在潜在宜居区的地球类似行星上确认大气层存在。 这项发现表明，尽管红矮星活动强烈，其周围的岩石行星仍能保留大气层，为寻找宜居世界开辟了新可能。同时验证了 JWST 表征温带系外行星大气的潜力，让我们更接近寻找生物特征。 LHS 1140b 比地球更大且更冷，通过 JWST 在二次掩星期间进行的发射光谱分析，探测到其富含氦气的大气层。该大气特征排除了迷你海王星的可能性，确认了其岩石性质。

hackernews · neversaydie · 7月17日 14:06 · [社区讨论](https://news.ycombinator.com/item?id=48947560)

**背景**: 红矮星是银河系中最常见的恒星，但其宜居带非常靠近恒星，使行星面临强烈的耀斑和大气剥离。探测此类行星的大气层极具挑战性；JWST 的红外灵敏度使其成为可能。此前，系外行星大气探测大多针对热木星，而非岩石行星。

## [华为发布昇腾 950 超节点，宣称性能达英伟达 6.7 倍](https://www.ithome.com/0/978/019.htm) ⭐️ 8.0/10

华为在 2026 世界人工智能大会上首次公开亮相昇腾 950 超节点（Atlas 950 SuperPoD），宣称其总算力达到英伟达同级 NVL144 系统的 6.7 倍。 这一发布标志着 AI 硬件领域可能发生范式转变，华为以大幅性能优势挑战英伟达的主导地位，可能重塑 AI 计算格局，尤其在中国的生态中。 昇腾 950 超节点通过灵衢互联协议支持多达 1024 张昇腾处理器，提供 1 EFLOPS FP8 和 2 EFLOPS FP4 算力，统一内存达 256 TB，基于超节点架构。
