## [LG Monitors Silently Install Software via Windows Update](https://videocardz.com/newz/lg-monitors-silently-install-software-through-windows-update-without-user-consent) ⭐️ 9.0/10

LG monitors are found to silently install software through Windows Update when connected to a PC via HDMI, without obtaining user consent. The software is installed automatically and runs at system startup with full system access. This practice undermines user trust and control, as software is installed without consent and with elevated privileges. It raises serious security concerns, as any third-party software with internet access and full system permissions could be exploited. The installation triggers immediately upon connecting an LG monitor via HDMI, and persists across reboots. Users can disable this behavior by enabling the 'Prevent automatic download of applications associated with device metadata' policy in Group Policy or by changing Device Installation Settings to 'No'.

hackernews · baranul · Jul 18, 10:21 · [Discussion](https://news.ycombinator.com/item?id=48956688)

**Background**: Windows Update allows hardware vendors to distribute driver packages, which can include software other than drivers. This mechanism is intended for convenience but can be abused to install unwanted applications. The LG monitor software installation appears to use this channel without explicit user consent.

## [Interactive Map of GPT-2 Token Embeddings Released](https://www.reddit.com/r/MachineLearning/comments/1v09muj/interactive_map_of_gpt2s_token_embedding_space/) ⭐️ 8.0/10

A developer released an interactive web-based map that visualizes 32,070 alphabetic tokens from GPT-2-small's token embedding space using t-SNE and a minimum spanning tree, allowing users to tap any token to explore its nearest neighbors. This tool makes GPT-2's internal token representations more interpretable, enabling researchers and practitioners to intuitively explore semantic relationships between tokens without running model inference. The map is built from GPT-2-small's learned weight embeddings (WTE) and uses t-SNE for dimensionality reduction, with edges representing a minimum spanning tree to show nearest-kin relationships. It works on mobile and includes a search box for jumping to any token.

reddit · r/MachineLearning · /u/Limp-Contest-7309 · Jul 18, 22:42

**Background**: Token embeddings are dense vector representations that encode the meaning of tokens (subwords) in a language model. GPT-2-small has a vocabulary of about 50,000 tokens, each mapped to a 768-dimensional vector. t-SNE is a nonlinear dimensionality reduction technique commonly used for visualizing high-dimensional data, while a minimum spanning tree connects all points with the smallest total edge weight, highlighting close relationships.
