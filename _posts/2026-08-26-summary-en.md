## [EVE Online Begins Massive Python 3 Migration Using Futurize](https://simonwillison.net/2026/Aug/25/eve-online-move-to-python-3/) ⭐️ 8.0/10

EVE Online announced the start of its long-awaited migration from Stackless Python 2.7 to Python 3, leveraging the futurize script on 2.4 million lines of code. The upgrade will require manual review of approximately 20,000 places where Python 2 and 3 behaviors differ. This migration is significant as EVE Online is one of the largest and longest-running Python codebases in production, providing a valuable real-world case study for Python 3 adoption. Its success or failure could inform how other legacy Stackless Python projects approach modernization. The announcement does not specify how Stackless will be replaced, but last year's EVE Frontier presentation described replacing Stackless with the open-source carbonengine/scheduler library. The migration uses futurize, which can automatically rewrite Python 2 code to be Python 2/3 compatible, followed by manual review of semantic differences like integer division.

rss · Simon Willison · Aug 25, 22:59

**Background**: Stackless Python is an enhanced version of Python that avoids relying on the C call stack, enabling microthreads called tasklets, which allow hundreds of thousands of concurrent tasks. EVE Online has run on Stackless Python since its launch in 2003, with its last major upgrade being Stackless Python 2.7 in 2010. Python 2 reached end-of-life in 2020, and Stackless Python itself was officially discontinued and its GitHub archive was archived in February 2025.

## [Continual Learning on Open-Weight Models Offers Path to SovereignAI](https://www.reddit.com/r/MachineLearning/comments/1vxvzju/continual_learning_of_frontier_models_for/) ⭐️ 8.0/10

A new technical report from TRI-FAIR Lab argues that institutions with modest budgets can reach frontier-model performance by continually learning on existing open-weight models. The report introduces Thomson, an open-weights general-purpose frontier model focused on high-stakes professional tasks, with the paper and weights publicly released. This challenges the assumption that frontier AI is only achievable by a few heavily funded labs, offering a concrete technical path to SovereignAI for a wider range of organizations. If validated, it could reshape AI governance and democratize ownership of models, tools, values, and data privacy. The approach uses a modern mid- and post-training stack with safeguards to preserve plasticity and stability, claiming improvements comparable to gains across multiple model generations. Thomson shows a 'π-shaped' evaluation pattern: broad improvements across many capabilities with minimal forgetting, at substantially lower compute and personnel costs.

reddit · r/MachineLearning · /u/Forsaken_Scientist · Aug 25, 10:30

**Background**: Continual learning is an AI training paradigm in which a model is sequentially trained on new tasks while preserving previously learned knowledge, avoiding the 'catastrophic forgetting' seen in naive fine-tuning. Open-weight models release trained weights for download and fine-tuning but do not necessarily disclose training data, unlike true open-source AI. SovereignAI refers to an organization's ability to independently build, deploy, and govern its own AI systems, a goal that has been seen as difficult for all but the largest players.
